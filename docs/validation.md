# 当前交付与验证

更新日期：2026-11-07。以下为当前源码和本次安装包的实测结果；编译目标不等于旧系统实机认证。

## 本次改动

- 协议菜单复查：会话/组织发生变化或有更新的连接方式请求时关闭旧菜单；为请求和缓存增加版本检查，丢弃乱序结果，30 秒到期时将旧菜单替换为重试入口。禁用资产不请求或触发协议连接，连接弹窗在会话变化时关闭；普通连接独立查询连接方式，不依赖已关闭的菜单请求。
- Qt 5/6 全量测试各 6/6 组通过；本地模拟验证请求乱序、切换组织后切回原组织、禁用资产、失败重试及菜单关闭后直接连接；Cocoa 原生菜单专项通过。测试未连接真实站点，令牌提交仍由站点验证实时权限。
- 协议菜单后台获取当前资产授权详情，结合站点和当前 OS 的连接方式筛选；连接方式按会话范围缓存 30 秒，资产授权每次获取。仅展示有效客户端方式、支持远程/虚拟应用，空授权及请求失败提供明确原因和重试。切换站点/组织或关闭菜单后忽略过期响应；选中协议复用详情打开连接设置，令牌接口再次执行服务端权限校验。
- Qt 5/6 全量 CTest 各 6/6 组通过；offscreen 下原生标题栏与系统凭据库用例按设计跳过。合成 HTTP 服务验证首次查询、操作系统参数、权限撤销、连接方式缓存、非法终端协议过滤、DB2 远程应用、失败重试及组织切换时丢弃响应；Cocoa 原生菜单重试测试通过。
- macOS 主窗口及弹窗的 AppKit appearance 随应用浅色/深色即时更新；跟随系统时恢复继承。Qt 5/6 Cocoa 实际窗口测试通过，自动测试的 offscreen 原生用例按设计跳过。Windows 使用动态加载的 DWM 深色及 Windows 11 标题栏颜色属性，x86/x64 用合成 Qt 桩交叉编译通过，Windows 实机未验证；旧系统及不支持的属性回退到原生外观。Linux/UOS/麒麟的窗口装饰由桌面环境决定，Qt 5 无统一接口，尚未针对具体桌面适配及实机验证。
- 主题跟随系统时使用独立保存的系统调色板，避免应用自身调色板影响判断；收到系统调色板更新后重新应用当前主题。Qt 5/6 全量测试各 5/5 通过，Cocoa 使用合成调色板验证即时切换；实际操作系统外观切换尚未实测。
- 菜单子菜单箭头采用与界面一致的 14px 细线图标，适配左右布局及深浅主题；macOS Cocoa 实际菜单预览已检查。
- 根目录新增 `build.sh`，统一配置、构建、测试、部署和打包；支持系统/架构/格式/Qt/Go/版本/签名参数及 dry-run。使用此入口实际重建两份 macOS 包；参数说明见 [构建主入口](../packaging/build-entry.md)。
- 设置弹窗与连接弹窗共用定位函数，首次相对主窗口居中上移 24px，切换设置页面或再次显示保留用户拖动的位置。其他资产即使只有一个本地连接方式，也统一显示类别页签与下拉框；只展示后端提供的有效类别。
- 连接弹窗首次打开时，按自适应后的完整窗口尺寸（含原生标题栏）相对主窗口居中并上移 24px，以主窗口所在屏幕计算高度和边界。后续协议/账号字段变化保留窗口左上角及用户拖动的位置；仅在超出可用屏幕时调整，并留出 16px 边距。
- 列表收藏列使用空心/主题色实心星标，支持鼠标点击和键盘空格收藏/取消收藏。复用现有 POST/DELETE 接口，请求期间阻止重复操作，失败保持原状态，成功同步卡片/列表；在“我的收藏”中取消后移除对应行。星标点击保留已有行选择，收藏列双击不触发连接。
- 补充 DB2 图标，复用 Lina 的 `src/assets/img/icons/db2.png` 高清资源；卡片和列表使用同一映射，资产类型大小写统一处理。
- 资产列表的名称、地址、账号、平台表头及内容统一左对齐；收藏、协议和操作列居中。协议使用主题色标签，空字段显示淡色 `—`，禁用资产降低对比度。
- 统一行高和内边距，弱化分隔线，增加整行悬停反馈；长文本单行省略并保留完整悬浮提示。文本列按窗口宽度分配空间，窄窗口允许横向滚动，操作列计入单元格内边距，避免英文和大字号按钮被裁切。
- 远程桌面“键盘布局”改为统一主题下拉框，按后端 `apps/users/const.py` 的 `KeyboardLayout` 提供 21 种布局；使用中英文显示名，保存和提交后端原始键值。默认美国英语 QWERTY，保留已有自定义值及未指定值；打开设置不会自动覆盖历史配置。
- 深浅主题共用布局，沿用现有 Go helper、`jms://`、OAuth、连接方式分类下拉及远程应用/虚拟应用的 token → client-url → helper 调用链。

新增收藏回归验证真实本地 HTTP POST/DELETE、成功/拒绝结果、鼠标/键盘操作、失败状态保留、行选择保持、收藏列表移除，以及收藏列双击不会连接。键盘布局回归验证默认值、保存、重新打开恢复、自定义值和空值保留，以及 RDP 请求中的 `connect_options.keyboard_layout`。表格矩阵检查对齐、空值、省略策略及连接按钮边界。完整服务测试包含此前修复的真实本地 TLS、OAuth、资产与远程应用请求回归。

本轮补充设置弹窗页面切换/重显位置保留、SSH/RDP/VNC/SFTP/MySQL/DB2 单选方式仍显示页签等回归。Shell 分支覆盖 DMG、EXE/MSI、DEB/RPM、多种架构、路径空格、拒绝非法参数及覆盖已有交付；CI 已纳入这些回归。Windows/Linux 仅验证命令分发，未在本机生成对应系统安装包。
